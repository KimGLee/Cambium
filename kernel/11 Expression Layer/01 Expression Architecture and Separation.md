## Purpose

Expression artifacts registered by the `Expression Layer Entry` are stored independently of canonical knowledge and link back to their knowledge owners through resolvable wiki links. Expression ordering, practice material, or evaluation material MUST NOT contaminate the definition, mechanism, and fact owner of canonical notes.

## Core Separation

```text
Canonical Knowledge = understand and own the subject
Expression Role = express the subject
Practice Role = retrieve and rehearse the subject
Evaluation Role = evaluate the expression
Sequence Role = order the work
```

The selected profile MAY bind these roles to one or more concrete artifacts, but MUST NOT interpret a role merger as a transfer of ownership. A canonical note does not store complete derived expressions, practice sets, or evaluation sets; it retains only the minimal context needed to understand the current knowledge and a wiki link to the corresponding expression artifact.

For the base rules of ownership, see [[kernel/03 Note Types and Ownership/02 Ownership and Canonical Notes|Ownership and Canonical Notes]].

## Physical Structure

Logical classification does not require creating physical directories with no content in advance. Create a directory only when an actual artifact needs a home; any directory migration MUST still satisfy the [[kernel/01 Scope and Architecture/04 Folder and Shared Ownership#Physical Folder Policy|Physical Folder Policy]] and follow the [[kernel/11 Expression Layer/07 Expression Migration Audit and Acceptance#Migration Policy|Migration Policy]].
