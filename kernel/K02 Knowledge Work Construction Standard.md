## Purpose

This page is the stable entry point of the Knowledge Work Construction standard. The former K02 content has been distributed between this knowledge-work module and [[kernel/K13 Task Runtime and Execution Control Standard|K13 Task Runtime and Execution Control]] by responsibility; the original rule text has not been reduced.

## Reading Rule

- First use this MOC to locate the rule owner, then read the modules required by the current task, event, or quality gate.
- Entering this domain does not require reading all modules at once.
- Each module returns to its parent via `Navigation` and links to the adjacent modules before and after it.
