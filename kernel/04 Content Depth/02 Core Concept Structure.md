## Core Concept Structure

A core concept SHOULD usually include:

```text
Position In The Knowledge System
Problem It Solves
Definition
Intuition
Core Mechanism
Mathematical Formulation / Data Flow
Step-by-step Example
Assumptions
When To Use
When Not To Use
Tradeoffs
Failure Modes
Debugging And Diagnosis
Comparison With Alternatives
Production Considerations
Evaluation
Expression Layer Link
Related
Sources
```

Mechanical use of all headings is not required, but these questions MUST NOT remain unanswered over the long term.
