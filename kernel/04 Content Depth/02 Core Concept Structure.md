## Core Concept Structure

核心概念通常应包含：

```text
Position In The Knowledge System（在知识体系中的位置）
Problem It Solves（解决的问题）
Definition（定义）
Intuition（直觉理解）
Core Mechanism（核心机制）
Mathematical Formulation / Data Flow（数学表述 / 数据流）
Step-by-step Example（逐步示例）
Assumptions（假设）
When To Use（适用场景）
When Not To Use（不适用场景）
Tradeoffs（权衡）
Failure Modes（失败模式）
Debugging And Diagnosis（调试与诊断）
Comparison With Alternatives（与替代方案的比较）
Production Considerations（生产环境考虑）
Evaluation（评估）
Expression Layer Link（表达层链接）
Related（相关）
Sources（来源）
```

不要求机械使用全部标题，但这些问题不能长期缺失。
