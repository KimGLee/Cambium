## Purpose

用于创建、迁移或审查独立 Interview Cards、分层回答、系统深挖、Roadmap 和 Question Bank。

## Start

先读取 [[Knowledge Base Standards/Read Sets/01 Core Bootstrap Read Set|Core Bootstrap]]，再读取：

- [[11 Interview Content/01 Interview Architecture and Separation|Interview Architecture and Separation]]
- [[11 Interview Content/02 Card Granularity Coverage and Categories|Card Granularity Coverage and Categories]]
- [[Knowledge Base Standards/11 Interview Content/03 Card Structure and Answer Levels|Card Structure and Answer Levels]]
- [[Knowledge Base Standards/11 Interview Content/04 System Deep Dive and Bilingual Policy|System Deep Dive and Bilingual Policy]]
- [[11 Interview Content/05 Knowledge Links and Preparation|Knowledge Links and Preparation]]
- [[kernel/04 Content Depth/01 Depth Model and Foundation|Depth Model and Foundation]]
- [[kernel/09 Wiki Link and Navigation/01 Link Semantics and Body Links|Link Semantics and Body Links]]
- [[Knowledge Base Standards/10 Writing and Formatting/05 Chinese-first Technical Language|Chinese-first Technical Language]]，用于区分中文知识表达与独立 English Answer 例外。

Interview expression 必须依赖已经足够完整的 canonical knowledge；不能用卡片替代知识正文。

## Triggered

- Roadmap 或 Question Bank：读取 [[Knowledge Base Standards/11 Interview Content/06 Roadmap and Question Bank|Roadmap and Question Bank]]。
- 从知识页迁移旧 Interview Answer：读取 [[Knowledge Base Standards/11 Interview Content/07 Migration Audit and Acceptance|Migration Audit and Acceptance]]。
- 新增术语解释：依次读取 [[kernel/05 Terminology/01 Terminology Extraction|Terminology Extraction]]、[[kernel/05 Terminology/02 Ownership and Term Structure|Ownership and Term Structure]]、[[kernel/05 Terminology/03 Naming Context and Linking|Naming Context and Linking]] 和 [[kernel/05 Terminology/04 Terminology Acceptance|Interview and Acceptance]]。
- Canonical knowledge 不足：组合 [[Knowledge Base Standards/Read Sets/02 Single Note Authoring Read Set|Single Note Authoring]] 或 [[Knowledge Base Standards/Read Sets/03 Module Build Read Set|Module Build]]。

## Gate

- [[Knowledge Base Standards/12 Quality Assurance/04 Guidance Source and Interview Review|Guidance Source and Interview Review]]
- 迁移任务还必须通过 [[Knowledge Base Standards/11 Interview Content/07 Migration Audit and Acceptance|Migration Audit and Acceptance]]。
