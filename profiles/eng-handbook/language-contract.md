# Language Contract

Implements the `Language Contract` slot for `eng-handbook`.

## Body Language

- All body text is English. No second display language is registered.
- Service names, alert names, and internal tool names are written exactly as they appear in the production configuration (case-sensitive), on first use and thereafter.

## Display Labels

- Headings are plain English; no bilingual label format is in effect.
- Acronyms are expanded on first use per page: `SLO (service level objective)`, thereafter `SLO`.

## Content Length Units

- The kernel's soft length ranges are interpreted in **words** for this profile.
- The numeric ranges themselves are kernel-owned and unchanged; this contract only fixes the unit. Length remains a soft reference, not a gate.
