## P0 / P1 Grant Criteria

- `P0`：目标岗位必须掌握，缺失会阻断其它内容。
- `P1`：高频或重要扩展，应达到 interview-ready。

Priority 由岗位需求、依赖关系、面试频率和系统影响共同决定。

Agent/Harness 主线核心满足本 profile 的 P0 授予条件。

本 rubric 只授予 P0 / P1，不改变 kernel 的 P0 / P1 / P2 三级轴、tier 派生或配额挂钩机制。
