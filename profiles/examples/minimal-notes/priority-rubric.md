## Profile-owned Grant Criteria

Every in-scope page stays at the kernel P2 fallback. This profile grants no P0 and no P1 because it has exactly one reader, who is also the only maintainer: no page protects a capability or deadline that is not already this reader's own, so a grant predicate would classify without changing anything.

| Priority | Testable grant predicate (`No grants` if always false) | Protected reader capability or time horizon (`Not applicable` for no grants) |
|---|---|---|
| `P0` | No grants | Not applicable |
| `P1` | No grants | Not applicable |
