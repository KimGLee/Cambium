# R04 Source-driven Expansion Card

## Purpose

Turn admitted sources or source leads into traceable updates without treating source capture as automatic canonical promotion.

## Actions

- Bound the source scope, target questions, and affected canonical owners.
- Separate reported facts, inference, synthesis, recommendation, uncertainty, and disagreement while preserving source identity.
- Route each accepted result to its canonical owner; combine R02 when a page is created or changed.
- Require `source-promotion` before a source-driven new canonical page is promoted.

## Stop or escalate

- Stop when authority, comparability, provenance, or the canonical owner cannot be determined from admitted evidence.
- Escalate when the source implies a scope, Standards, or Profile change.

## Read-back hook

Resolve `R04:semantic-condition` for terminology, source quality, uncertainty, or another implicated route; use the gate edge before promotion or acceptance.
